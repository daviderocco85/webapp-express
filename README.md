# WebApp express

Sviluppo del back-end di una Web App realizzata con Express.js, dedicata a più bei monumenti d'Italia corredata dalle relative recensioni.

# Obiettivi

- Creazione di un database con **MySQL Workbench**.
- Creazione di una nuova applicazione **Express.js**.
- Integrare l’app con il **Database MySQL** e verificarne il corretto funzionamento.
- Sviluppo di un **Endpoint API** `index` per ottenere la lista di tutti i monumenti.
- Implementazione di **Endpoint API** `show` per ottenere i dettagli di un singolo monumento e le sue recensioni.

## Bonus 

- Configurazione della gestione degli asset statici tramite **Express.js**.
- Gestione delle credenziali e dei parametri di connessione al database tramite **variabili d'ambiente**.
- Organizzazione della logica applicativa in appositi `controller`.
- Definizione e gestione degli **Endpoint API** tramite `router` dedicati.
- Implementazione di un `middleware` per la gestione delle **rotte non esistenti**.
- Implementazione di un `middleware` centralizzato per la **gestione degli errori** dell'applicazione.
